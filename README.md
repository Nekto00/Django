# Проект "Интернет магазин на Django"

## Проект "Интернет магазин на Django" - Это полнофункциональный интернет-магазин, разрабатываемый на Django в рамках учебного курса. Проект будет постепенно дополняться новым функционалом на каждом уроке.

## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/username/project-x.git
```
2. Установите зависимости:
```
pip install -r requirements.txt
```

## Использование:

1. Откройте приложение в вашем веб-браузере.
2. Зайдите по ссылке.
3. Зайдите во вкладку каталог, чтобы выбрать товар и контакты, чтобы связаться.


Запуск:  
```
python -m pytest
```
